# React Starter

This is a starting point for developing React websites, it uses vite as a development server and requires <a href="https://nodejs.org/">Node.Js</a> to run.

## Instructions

I recommend to install and use git, but you don't have to, but with git run:
```bash
git clone https://github.com/SHAPeS-Software/React-Starter.git
```

or on the repo page click **<> Code v** and **Download Zip** and save it somewhere.

#### Node.JS and Vite
Install Node.Js from <a href="https://nodejs.org/">this</a> website run:
```bash
npm install vite --save-dev
```
## Files
This project contains multiple files (as react is a lot more complex) this repo assumes you have some experience with Node, React, and starting development servers.
- index.html | Used to link React, not to be modified too frequently
- **public/** | where static assets
    - favicon.ico | the icon of the site
- **src/** | Where the code goes
    - **assets/** | files to be processed by Webpack
    - index.css | Main styling
    - main.jsx | Main JSX file
    - App.jsx | React App component
