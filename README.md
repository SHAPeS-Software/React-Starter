# React Starter

This is a starting point for developing React websites. It uses Vite as a development server and requires [Node.js](https://nodejs.org/) to run.

## Instructions

Using Git is recommended, but not required. To clone the repository with Git, run:
```bash
git clone https://github.com/SHAPeS-Software/React-Starter.git
```

Alternatively, on the repository page, click **<> Code** and select **Download ZIP** to save it locally.

#### Node.js and Vite
Install Node.js from [the official website](https://nodejs.org/). Then, in your project directory, run:
```bash
npm install vite --save-dev
```

## Files
This project contains multiple files (as React projects are more complex). This repo assumes you have some experience with Node, React, and starting development servers.
- `index.html` | Used to link React; should not be modified frequently
- **public/** | Where static assets are stored
    - `favicon.ico` | The site icon
- **src/** | Where the code goes
    - **assets/** | Files to be processed by Webpack
    - `index.css` | Main styling
    - `main.jsx` | Main JSX entry file
    - `App.jsx` | React App component
